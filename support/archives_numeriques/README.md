# Anciennes données numériques

Ces données brutes proviennent des études précédant le nettoyage du code. Elles sont conservées pour retrouver les anciens calculs. Les figures correspondantes ont été retirées.

Les calculs actuels et les figures de la présentation se trouvent dans `support/resultats_antoine/`. Il faut utiliser leurs paramètres et leurs indicateurs pour interpréter les nouveaux résultats.

Les anciens chiffres ne sont pas attribués aux nouvelles descentes. Les dossiers et fichiers gardent leur nom initial pour conserver leur provenance.
